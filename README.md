# Industrial Survey & Inspection System

## Overview

Industrial Survey & Inspection System adalah aplikasi berbasis web yang dirancang untuk membantu proses survei, inspeksi, dan pendataan peralatan industri secara terpusat.

Sistem ini memungkinkan perusahaan untuk melakukan pencatatan hasil inspeksi, dokumentasi foto, pengelolaan temuan, serta pelaporan kondisi peralatan dengan lebih cepat, akurat, dan terdokumentasi dengan baik.

---

## Objectives

* Digitalisasi proses inspeksi dan survei peralatan.
* Mengurangi penggunaan formulir manual.
* Mempermudah pencarian data historis inspeksi.
* Menyediakan dokumentasi temuan dan rekomendasi perbaikan.
* Meningkatkan efisiensi proses monitoring aset dan peralatan.

---

## Main Features

### User Management

* Login dan autentikasi pengguna.
* Multi-level user access.
* Pengelolaan hak akses berdasarkan peran.

### Equipment Management

* Penyimpanan data master peralatan.
* Kategorisasi unit dan lokasi.
* Pencarian dan pengelolaan data peralatan.

### Excel Import

* Import data peralatan dari file Excel.
* Validasi data sebelum masuk ke sistem.
* Mempercepat proses migrasi data dari sistem lama.

### Survey & Inspection

* Pencatatan hasil inspeksi.
* Pengelolaan temuan inspeksi.
* Rekomendasi tindak lanjut.
* Dokumentasi foto unit dan foto temuan.

### Dashboard & Reporting

* Statistik inspeksi.
* Monitoring jumlah peralatan.
* Riwayat inspeksi.
* Rekap hasil pemeriksaan.

---

## User Roles

### Super Administrator

Mengelola seluruh sistem dan pengguna.

### Administrator

Mengelola data master dan proses import.

### Supervisor

Melakukan review dan persetujuan hasil inspeksi.

### Inspector

Melakukan inspeksi lapangan dan penginputan data.
